## Instalação
- Node.js 16+ instalado

1. **Clone o repositório:**
    ```sh
    git clone https://github.com/FoolioClear/bloodhound.git
    cd bloodhound
    ```

2. **Instale as dependências:**
    ```sh
    npm install
    ```

3. **Inicie o script:**
    ```sh
    node index.js
    ```
